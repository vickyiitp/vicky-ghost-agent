##  Installation & Usage

### 1. Setup
```bash
git clone https://github.com/vickyiitp/vicky-ghost-agent
cd vicky-ghost-agent
pip install -r ghost-engine/requirements.txt
playwright install
```

### 2. Configuration
Create a `.env` file in `ghost-engine/`:
```env
GEMINI_API_KEYS=your_key_1,your_key_2,your_key_3
```

### 3. Launch
**Developer Mode:**
```bash
python start_ghost.py
```

**Field Mode (Executable):**
Run `VickyGhostAgent.exe` (Generated via PyInstaller).
